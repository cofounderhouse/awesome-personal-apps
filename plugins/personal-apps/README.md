# Personal apps (all apps)

Every personal app from the Cofounder House Library in one plugin, version 1.0.6. Each app is a skill that runs on files you share, such as a help desk export or meeting notes, and sends nothing anywhere. New apps arrive with each update, so turn on auto-update for the marketplace.

**Pick one:** install this plugin or the single apps, not both. With both, the same skill shows twice.

## Apps

- `weekly-ticket-summary`: For support and ops leads who review a ticket queue every week: one export in, four checked AI steps, and a page of themes and urgent tickets out.
